# C2f — Observation/Language Detector Data Specification

**Status**: draft contract for the post-D7 detector route.

C2f starts because D8F closed the 25D-only route: proprio/action features are sufficient for Object/Goal/Spatial contact phases but insufficient for LIBERO-10 primary-vs-distractor disambiguation.

## Goal

Train a clean-only online detector that can identify the attackable primary event in long-horizon language-conditioned manipulation by using:

- RGB observation or frozen RGB embedding
- task language or frozen language embedding
- 25D causal proprio/action temporal features
- 108D suite/task context

The detector must remain deployable: no privileged simulator state, no attack outcome, no manual failure label, and no matched attacked-run result may be used as student input.

## Allowed student inputs

Per step `t`:

| Field | Type | Notes |
|---|---|---|
| `rgb_path` | string | Relative path to RGB frame for step `t`. Prefer agentview/front camera. |
| `task_language` | string | Original LIBERO task instruction. Same for all steps in an episode. |
| `features_25d` | list[float], length 25 | Same canonical order as C2e3 runtime. |
| `action` | list[float] | Optional; only for feature reconstruction/QC, not mandatory if 25D already present. |
| `suite` | string | `libero_object`, `libero_goal`, `libero_spatial`, `libero_10`. |
| `task_index` | int | Task index within suite. |
| `parent_key` | string | Stable clean parent/trajectory key. |
| `step` | int | Online step index. |

Context inputs:

- `X_context_108d`, if available, must be generated by the same lookup policy used by C2e3.
- If not available, materialization scripts must create and checksum a deterministic context lookup.

## Teacher labels allowed only for supervision

Teacher labels may be generated from clean privileged simulation state, but must not be passed to the deployed student.

Per step labels:

| Field | Type | Meaning |
|---|---|---|
| `teacher_hazard` | 0/1 | In attackable contact-critical corridor. |
| `teacher_primary_attackable` | 0/1 | The current event is the task-primary attackable event. |
| `teacher_release_safe` | 0/1 | Release-safe / post-critical phase. |
| `teacher_event_role` | string | One of `primary_attackable`, `auxiliary_manipulation`, `distractor_or_setup`, `unsupported_or_abstain`. |
| `teacher_phase` | string | Optional phase name for audit. |

Episode-level labels:

- `clean_success`
- `teacher_label_version`
- `teacher_config_sha256`
- `artifact_sha256`

## Forbidden student inputs

Never include any of the following in model input tensors:

- object pose
- target pose
- object-target distance
- privileged object id / target id from simulator
- attack condition
- attack success/failure outcome
- manual video failure label
- matched attacked-run result
- future frames or future actions
- normalized global timestep if the experiment claims no explicit timing shortcut

Privileged fields may be stored in a separate `teacher_privileged_step_records.jsonl` for audit only. They must not be read by C2f student training scripts.

## Required artifact layout

```text
<c2f_root>/
  manifest.json
  SHA256SUMS
  episodes/
    <suite>/<parent_key>/
      episode_metadata.json
      step_records.jsonl
      rgb/
        frame_000000.png
        frame_000001.png
        ...
      teacher_labels.jsonl              # optional if labels are already in step_records
      teacher_privileged_step_records.jsonl  # optional, audit-only, forbidden for student
```

`episode_metadata.json` must contain:

```json
{
  "schema": "C2F_OBS_LANG_CLEAN_EPISODE_V1",
  "suite": "libero_10",
  "task_index": 0,
  "task_name": "...",
  "task_language": "...",
  "parent_key": "...",
  "condition": "CLEAN",
  "n_steps": 0,
  "clean_success": true,
  "student_allowed_modalities": ["rgb", "task_language", "features_25d", "context_108d"],
  "student_forbidden_modalities": ["object_pose", "target_pose", "attack_outcome", "manual_failure_label"],
  "source_commit": "...",
  "collector_commit": "..."
}
```

`step_records.jsonl` record example:

```json
{
  "step": 42,
  "rgb_path": "rgb/frame_000042.png",
  "features_25d": [0.0, 0.0],
  "task_language": "put the ...",
  "teacher_hazard": 1,
  "teacher_primary_attackable": 1,
  "teacher_release_safe": 0,
  "teacher_event_role": "primary_attackable",
  "teacher_phase": "stable_carry"
}
```

## Split policy

Splits must be parent/trajectory based, not window based.

Recommended split:

- train: 70%
- val: 15%
- test: 15%

For L10 diagnostics, additionally report task-balanced and suite-balanced metrics. Do not use D7B2 outcomes for training or threshold selection.

## C2f minimum gates

A C2f candidate may only be considered a detector candidate if it satisfies held-out test gates:

```text
L10 recall >= 45.6%          # at least C2e3 baseline
L10 FP <= C2e3 L10 FP
Overall FP <= 30%
Object/Goal/Spatial do not collapse
Macro-F1 improves over C2e3 or gives a clearly useful Pareto trade-off
Runtime contract: normalization + embedding + context provenance PASS
```

## Boundaries

C2f is a post-D7 detector route. It must not affect D7B2 Table 1, D7C, D7D, or D7E.
