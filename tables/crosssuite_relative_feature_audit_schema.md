# CrossSuite Relative Feature Audit Schema

Generated by `scripts/diagnostics/crosssuite_feature_transform_audit.py`.

Columns:

- `suite`
- `feature`
- `transform`: `raw` or `relative_initial`
- `n`
- `mean`
- `std`
- `min`
- `max`
- `missing_rate`
- `nan_rate`
- `inf_rate`
- `zero_rate`
- `object_mean_abs_distance`

The `relative_initial` transform uses only episode-initial EEF values, so it is compatible with causal deployment. It does not use future full-trajectory normalization.
